# MTTL Control 0.0.1 Alpha 3

Windows-only update providing a clear path to add a strip after joining its setup Wi-Fi manually.

- Shows the setup Wi-Fi name and the password to join the strip, including when entering the SSID manually.
- Uses direct provisioning on Windows after the user connects, avoiding unsupported automatic network switching.
- Guides users through entering destination credentials, joining the strip, sending settings, returning to the destination network, and verifying a fresh controller connection.
- Supports continuing without scanning when already connected to the strip.
- Keeps the destination controller address and credentials through network changes. Avoids guessing the destination address when the app is opened on the strip's temporary network.
- Connection verification can be retried without sending setup commands again. Pairing steps and recovery instructions are available in Arabic and English.

## Downloads

Windows x64 installers: `-setup.exe` and `.msi`. `SHA256SUMS.txt` contains checksums for both downloads. Windows requires WebView2; the installer can download it if missing. Installers are unsigned.

Linux and macOS downloads remain available in [v0.0.1-alpha.1](https://github.com/AmrEmad0/MTTL-W01_APP/releases/tag/v0.0.1-alpha.1).

## Add a strip on Windows

1. While connected to your destination Wi-Fi, enter its SSID and password and this computer's IPv4 address on that network.
2. Choose the strip. Open the Windows Wi-Fi menu and join its setup network using the password displayed in the app. Stay connected even if Windows reports no internet access.
3. Return to the app and select **I am connected — send settings**. If already connected to a strip, use **Already connected? Continue without scanning** instead of rescanning.
4. After the strip accepts the settings and restarts, reconnect the computer to the destination Wi-Fi.
5. Select **I reconnected — check connection**. Keep the app running and allow its controller connection through Windows Firewall on your private network if needed.

Wi-Fi scanning may require location access in **Settings > Privacy & security > Location**. Manual setup can continue without scanning. Physical-device operation still needs hands-on verification on Windows.

See the [README](https://github.com/AmrEmad0/MTTL-W01_APP#connect-a-strip) for remaining alpha limitations.
