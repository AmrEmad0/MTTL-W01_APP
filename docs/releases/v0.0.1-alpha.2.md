# MTTL Control 0.0.1 Alpha 2

Windows-only update fixing Wi-Fi discovery for MTTL-W01 setup access points.

- Uses the native Windows WLAN API for a fresh scan, avoiding terminal flashes and localized console output parsing.
- Preserves Unicode network names and distinguishes access points sharing the same SSID.
- Shows English and Arabic recovery instructions for blocked location access, disabled Wi-Fi, missing adapters, and the WLAN AutoConfig service.
- Hides console windows during ARP discovery and saved-profile connections.

## Downloads

Windows x64 installers: `-setup.exe` and `.msi`. `SHA256SUMS.txt` contains checksums for both downloads. Windows requires WebView2; the installer can download it if missing. Installers are unsigned.

This release does not include Linux or macOS builds. Use [v0.0.1-alpha.1](https://github.com/AmrEmad0/MTTL-W01_APP/releases/tag/v0.0.1-alpha.1) for those platforms.

## Wi-Fi discovery and setup

Enable Wi-Fi and the Windows WLAN AutoConfig service. If Windows denies scanning, enable Location services and app location access under **Settings > Privacy & security > Location**, then click **Scan Wi-Fi** again.

Automatic Wi-Fi switching remains Linux-only. On Windows, join the strip's setup access point manually before provisioning. Physical-device scanning and operation still need hands-on verification on Windows.

See the [README](https://github.com/AmrEmad0/MTTL-W01_APP#connect-a-strip) for connection steps and remaining alpha limitations.
