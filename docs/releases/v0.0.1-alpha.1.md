# MTTL Control 0.0.1 Alpha

First public alpha of MTTL Control, a local desktop controller for LG U+ / TONLY MTTL-W01 smart power strips. This is an early release; expect bugs and incomplete platform verification.

- Four-outlet controls, device setup, live readings, and protection status.
- History, power comparison, CSV export, schedules, timed sequences, and monitoring rules.
- Local SQLite storage with data management and a protocol console.
- Arabic and English, RTL support, and light and dark themes.
- MIT-licensed source with bundled dependency and font notices.

## Downloads

| System              | Download                       |
| ------------------- | ------------------------------ |
| Linux x64           | `.deb`, `.rpm`, or `.AppImage` |
| Windows x64         | `-setup.exe` or `.msi`         |
| macOS Apple Silicon | `darwin_aarch64.dmg`           |
| macOS Intel         | `darwin_x64.dmg`               |

Linux packages require WebKitGTK 4.1. AppImages still depend on compatible system libraries. Windows requires WebView2; the installer can download it if it is missing. Mount the macOS DMG and drag the app into Applications. `SHA256SUMS.txt` contains checksums for the downloads.

## Alpha limitations

Windows installers are unsigned. macOS apps use ad-hoc signatures and are not Apple-notarized. Your operating system may ask you to approve installation; see the [installation instructions](https://github.com/AmrEmad0/MTTL-W01_APP#install).

The release workflow runs automated checks on all four platforms before publishing downloads. Physical-device operation and the native interface still need hands-on verification on Windows and macOS. Automatic Wi-Fi switching is Linux-only; use manual device setup on Windows and macOS. Compatibility is based on reverse-engineered MTTL-W01 firmware `0.1.54-1.0.66`.

Keep the app running for schedules and monitoring. The device protocol is plaintext and unauthenticated; use a trusted local network. The Linux dependency graph has two documented upstream advisories in [SECURITY.md](https://github.com/AmrEmad0/MTTL-W01_APP/blob/main/SECURITY.md). Automatic app updates are not configured.

See the [README](https://github.com/AmrEmad0/MTTL-W01_APP#connect-a-strip) for connection steps and device behavior.
