# MTTL Control 0.0.1 Alpha 4

This release refreshes Linux, Windows, and macOS builds and addresses the
AppImage catalog startup-language test.

## Changes

- Fresh installations follow the system language: Arabic for Arabic systems,
  English for English, unsupported, or unset languages. Saved choices still
  take priority, including when changing between Arabic and English.
- Initial page language, direction, and title agree with the React interface.
- Linux download names omit the redundant `linux` token. The AppImage is
  `MTTL-Control_0.0.1-alpha.4_amd64.AppImage`.
- Release publishing runs only in the public MTTL-W01_APP repository; the
  development repository continues running Checks.
- Windows setup and native Wi-Fi discovery from Alpha 3 are retained.

## Installation and limitations

Download the installer for your operating system and verify it against
`SHA256SUMS.txt`. Linux builds use Ubuntu 22.04 and still require compatible
system libraries. Windows installers are unsigned; macOS builds use ad-hoc
signing without notarization. Automatic updates are not configured.

This remains an alpha release. Hardware commissioning and native behavior need
physical-device and operating-system testing. AppImage catalog acceptance
requires a successful retest after publication.
